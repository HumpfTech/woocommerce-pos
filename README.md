# WCPOS completed POS sale email designs

All examples use synthetic orders in a local WordPress and WooCommerce installation with Mailpit as its SMTP server.

The gallery and editor screenshots show desktop (1440px), tablet (820px) and phone (390px) views. Chromium verified that a saved draft appeared in the gallery, only a published design could be activated, and choosing the WooCommerce default persisted after reloading.

The Copper and Juniper images show the HTML from actual captured messages at 390px and 1024px. Each came from a completed POS order after selecting the corresponding design via the authenticated gallery REST route. Both matched the selected template preview on the store's design marker, order number, product and $25.00 total. Both messages contained HTML and had zero attachments. The viewport and document widths matched at both sizes. Email clients may render the same HTML differently.
